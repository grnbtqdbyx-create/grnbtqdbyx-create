# Wholesale / Reseller / White-Label Suppliers Behind "Guaranteed Placement" Press Release Resellers (MediaBoost-type) — Cost Table for Margin Analysis

**Method note (read first):** Every direct page fetch was blocked by the egress proxy (marketersmedia.com, mediaboost.press, brandpush.co, prnow.io, redpress.net, openpr.com, pressranger.com, blackhatworld.com, checkout.pressrelease.com all returned EGRESS_BLOCKED). **All figures below come from web-search snippets** (search engine summaries of the listed pages), not from reading the pages themselves. Treat every number as "reported by search snippet of the cited page" — confidence tags: **[S]** = snippet attributed to the supplier's own page; **[3P]** = third-party review/comparison site; **[MKT]** = marketplace gig listing; **[?]** = internally inconsistent or unverifiable. Prices as of 2025–2026, USD. Research date 2026-10-01.

## Q0. What exactly is MediaBoost selling (the retail side of the margin calculation)?

### Takeaway
MediaBoost (.press) sells four one-time packages — SaaS Directory $389, Web3 Media Lite $689, Global Media $899, Web3 Media Plus $1,599 — with "guaranteed placements on named outlets" from a "500+ outlet catalog averaging DR 82", 48-hour turnaround, editorial review, and a PDF proof report; named outlets include Yahoo, USA Today, NewsBreak, Barchart.

### Inferences
- The outlet mix MediaBoost advertises (Yahoo Finance, Business Insider/Markets Insider, AP News, Barchart, USA Today affiliate pages, NewsBreak, Digital Journal) is the same footprint marketed by MarketersMEDIA/PR.plus, King Newswire, BrandPush, Press Ranger, EasyPRWire, IMCWire and many Fiverr/BHW sellers (see Q1–Q3). This "500+ sites" footprint is a commodity syndication bundle (largely FinancialContent-powered market pages + Barchart "story" pages + TV-station/newspaper affiliate "markets" subdomains + AP News paid PR section + Yahoo Finance feed), which strongly suggests MediaBoost buys from one of these networks rather than placing directly.
- Evidence of the common pipe: PR.plus's own announcement was syndicated at `markets.financialcontent.com/wral/article/marketersmedia-2025-9-26-...` (URL slug shows MarketersMEDIA as the feed source on FinancialContent) and on `barchart.com/story/news/...` — [FinancialContent/WRAL copy](https://markets.financialcontent.com/wral/article/marketersmedia-2025-9-26-prplus-expands-distribution-to-bloomberg-business-insider-yahoo-finance-street-insider-barchart-digital-journal-benzinga-and-500-additional-outlets-at-the-same-cost); [Barchart copy](https://www.barchart.com/story/news/35048726/pr-plus-expands-distribution-to-bloomberg-business-insider-yahoo-finance-street-insider-barchart-digital-journal-benzinga-and-500-additional-outlets-at-the-same-cost)

### Gaps
- Could not read MediaBoost's package pages to see exactly which outlets each tier guarantees (e.g., whether $389 includes Yahoo Finance, or whether Web3 tiers include Cointelegraph/CoinMarketCap etc.). Needed to match each package to a specific upstream SKU.
- Upstream supplier of MediaBoost is not publicly identified anywhere found.

## Q4. Link attributes, turnaround, editorial restrictions, payment/API/white-label dashboards

### Takeaway
Syndicated press-release links are overwhelmingly nofollow (Google guidance; PRN/BW/GlobeNewswire default nofollow); dofollow is sold only as a gray-market "FinancialContent/telecom portal" package (~$160). Turnaround is typically same-day to 48h. White-label reports and APIs exist at PRNow (free API), Press Ranger, NewswireNEXT, EasyPRWire, BrandPush, eReleases, PressRelease.com; EIN Presswire has no public API.

### Cited Findings
- Google says press-release links should be nofollow; PR Newswire, Business Wire, GlobeNewswire apply nofollow by default — [24-7 Press Release article](https://www.24-7pressrelease.com/article/113/understanding-nofollow-links-why-theyre-standard-in-press-release-distribution); [verticalresponse](https://verticalresponse.com/blog/google-says-links-in-press-releases-should-be-nofollow/)
- "Dofollow Press Release Package" via FinancialContent market pages and telecom portals (CenturyLink, Windstream, Armstrong MyWire, Altafiber, Chronicle Journal, Hawaiian Telcom, GVTC) — [BrandingBuzz release](https://lifestyle.middletownlifemagazine.com/story/697009/brandingbuzz-agency-introduces-flexible-press-release-distribution-options-for-businesses-and-marketing-agencies/); ~$160 + fees [MKT] — [swapd](https://swapd.co/t/financialcontent-markets-press-release-service-specialized-financial-wire-target-investor-backlinks-do-follow-cheap-price/2119696)
- Turnaround: MediaBoost 48h ([MediaBoost](https://www.mediaboost.press/)); Chainwire same-day ([Chainwire](https://chainwire.org/pricing/)); IMCWire 24h standard, 6h expedited +$100 ([IMCWire](https://imcwire.com/pricing/)); PressRelease.com most live within 24h ([pressrelease.com](https://www.pressrelease.com/pricing)); EIN Presswire ~2h review after one-time verification of up to 2 business days ([EIN FAQ](https://www.einpresswire.com/faq)); ACCESS Newswire same-day ([G2](https://www.g2.com/products/access-newswire/pricing))
- APIs / dashboards: PRNow free API + white-label reports ([PRNow](https://prnow.io/white-label)); EIN Presswire — no public developer API, web-only submission ([EIN how it works](https://www.einpresswire.com/how-it-works)); Press Ranger multi-client agency dashboard + white-label reports ([resellers](https://pressranger.com/pages/resellers)); BrandPush agency account + free white-label report export, credit packs paid via secure payment link → coupon code credits ([BrandPush](https://www.brandpush.co/); [spendmoneysmart](https://spendmoneysmart.com/store/brandpush-co/)); MarketersMEDIA white-label PDF report with custom logo ([MM pricing](https://marketersmedia.com/plans-and-pricing)); eReleases white-label PRN credits w/ ReleaseWatch report ([eReleases reseller](https://www.ereleases.com/reseller/)); generic "reseller panels" with S2S API exist in the SMM world ([iluvsmmpanel](https://iluvsmmpanel.com/blog/telegram-reseller-panel-agency-profits)) — no PR-specific Telegram panel price list found.
- Sign-up routes: MarketersMEDIA Agency & Partner Program (contact for custom offer); BrandPush "apply for agency account"; King Newswire /resellers-plans/ page; Press Ranger /pages/resellers; PressRelease.com /resellers; eReleases /reseller/; PRNow self-serve white-label (single $15 release to test) — sources as in Q1 table.

### Inferences
- MediaBoost's "DR 82 average" claim refers to the domain authority of host sites, not link equity; buyers likely receive nofollow links on most placements.
- Restricted categories (crypto, CBD, gambling) are the main reason a reseller would route to BrandPush Access / MarketersMEDIA / King Newswire rather than PRN/BW — and the reason Web3 packages can carry premiums.

### Gaps
- Payment methods (crypto acceptance, net terms) for upstream suppliers not found. No confirmed API docs for MarketersMEDIA, King Newswire, BrandPush, or Newsfile.
